# 05 制作ルールとアセット規約

## 設定の正本
世界の法則=`01_WORLD_BIBLE.md`、人物／結末=`02_STORY_AND_CHARACTERS.md`、地域=`03_SEVEN_TRIALS.md`、機構=`04_GAME_DESIGN.md`。企画変更は`08_DECISIONS.md`を通す。複数文書で矛盾があれば、黙って統一せずIssueを作る。

## グラフィック原則
2Dのキャラクターを、3Dの地形・光・水・建築と組み合わせる。手描き／ピクセル／水彩などの細かい画風、解像度、キャラの基準寸法は**未決定**。特定既存作品の絵柄や固有デザインをトレースしない。

## アセット管理
- `assets/source/`：制作元（大容量のソースはGit LFS導入を検討）。
- `assets/export/`：エンジン投入用。ファイル名に空白や曖昧な版名を入れない。
- 例：`chr_hero_idle_s_0001.png`、`env_memory_forest_bridge_a.glb`、`sfx_echo_activate_01.wav`。
- 連番はゼロ埋め。色深度・透過・フレームレート・ピクセル寸法はアセット種別ごとに後日決定。
- 出典、作者、ライセンス、生成AI使用有無とプロンプト概要を `assets/ASSET_REGISTER.csv` に記録。

## AI生成物の品質確認
外見・世界観の整合、著作権・商標、画像の透過、アニメーション軸、寸法、境界ピクセル、ループ、ヒットボックスを人間がレビュー。大きな修正後に必ず実機／エンジン上で確認。

## イベント／ダイアログ
一つの会話に必要な設定を詰め込みすぎない。謎は行動・環境・人物の生活を通して見せる。世界の重要人物がなぜその結論に至ったかを記録する。

## 制作段階
`idea` → `approved` → `in_progress` → `review` → `done`。完成扱いには再現可能な確認結果が必要。

## インスピレーションと権利
『はてしない物語』や『聖剣伝説2』は**創作上の参考**。固有の人物、名称、ロゴ、音楽、地図、台詞、設定の細部、画面構成、特徴的なアートの再現はしない。公開・販売前に使用素材の権利を確認する。
