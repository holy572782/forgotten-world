# 04 ゲームデザイン

## 確かな方向性
2Dキャラ／3D地形、探索主体のアクションアドベンチャー、シームレス戦闘、『聖剣伝説2』のアクションゲージを参考にしたテンポ。七つの試練で得た能力を戦闘と探索に使う。

## 提案システム（仮）
- 攻撃：連続で振り回せるが、攻撃後にゲージ回復。満タン攻撃が最大威力。
- 強攻撃：一定条件下で高威力・特殊効果。
- 回避：スタミナ等を使用。無敵フレームは要テスト。
- 魔法／特殊能力：試練の能力をショートカットで使用。
- 敵：フィールド徘徊、視界・音・距離で反応。
- 仲間：戦闘AI付き最大2人という以前の提案は未確定。
- 成長：装備強化と能力解放中心の案。レベル制の有無は未決定。

## 残響の操作例
白化した橋へ近づく → 残響のヒント出現 → 発動で橋が一定時間だけ復元 → 制限中に渡る。回数・持続時間・失敗時の安全策・ボス戦応用をプロトタイプで確定する。

## 2D＋3Dの技術検証項目
- カメラ：見下ろし角度／擬似アイソメトリック／自由カメラを比較。
- スプライト：常時カメラ向き／8方向など、立体地形との相性を確認。
- 深度・影・遮蔽：壁裏表示、草むら、水中、照明との整合。
- 当たり判定：3Dコリジョンに対する2Dキャラの移動・坂・段差・ジャンプ。
- 敵と攻撃の当たり判定：表示見た目とヒット範囲が一致するか。
- パフォーマンス：広域ロード、敵AI、ポストエフェクト、端末負荷。

## 一画面の試作受け入れ条件
1. 3D地形を2Dキャラが走り回れる。
2. 敵に接近しても場面切り替えなしで戦える。
3. ゲージ量でダメージなど戦闘結果が変わる。
4. 回避と敵予兆が機能する。
5. 残響で消えた橋を復元し、渡ることができる。
6. セーブ→終了→ロードで状態が復帰する。

## 規模案
前回提案のメイン約13時間、探索込み約17時間は**企画上の仮置き**。個人制作では先に記憶の森まで作る縦切り試作を完成させ、工数を実測してから規模を確定する。
