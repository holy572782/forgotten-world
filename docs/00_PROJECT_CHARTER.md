# 00 プロジェクト憲章

- 仮タイトル：**忘れられた世界の旅人**／英語案 **THE LAST FABLE**。タイトルは未確定。
- ジャンル：幻想アクションアドベンチャー／アクションRPG。
- コアコンセプト：夢・記憶・願いが形になる世界を、七つの試練を越えながら救う。
- トーン：**神秘的で少し不気味**を主軸に、**王道冒険の高揚感**と**滅びゆく世界の切なさ**を融合。
- 表現：**2Dキャラクター＋3Dマップ**を目標。
- 戦闘：『聖剣伝説2』型のフィールドシームレス・アクションを参照する。ただしシステム表現は独自実装。
- フィールド：オープンワールド志向。七地域は原則自由に訪問でき、能力取得によって探索先が増える。
- メイン構造：**七つの試練**、その先に世界の真実と結末の選択。

## 世界の核となる合意済み設定
世界名：エルディア。人々の願いや記憶が風景・生物を形作る。地域が色と存在を失う「白化」が進行し、主人公はそれに抗う旅に出る。主人公だけは消えたものを覚え、能力「残響」で一時的に失われた物を戻せる。同行する不思議な相棒「ルゥ」がいる。七人の語り部と七つの願いが世界の成り立ちに関係する。物語の中心命題は「保存と変化」「願いと喪失」。

## 確定ではない企画案
七地域の固有名／ボス名／獲得スキル名、七人の歴史の詳細、ルゥの正体、3種エンディング、仲間最大2人、12〜18時間想定、武器成長方式は詳細承認前の案。正式な仕様にする際は決定ログに記録する。

## まだ決めていないこと
エンジン、ターゲット（PC／スマホ／家庭用）、入力、カメラ、グラフィック解像度、アセット単位、マップロード方式、セーブ方式、配信形態、チーム規模、予算、完成時期。

## ブランドの約束
- あらゆる地域に驚きと、探索して発見できる小さな物語がある。
- 地域ごとの独自ルールが、見た目だけでなく探索・戦闘・人物の暮らしに影響する。
- 戦闘だけでなく、選択・理解・他者への共感も試練の突破方法になる。
- 驚きと奇妙さを優先し、説明過多・単純な善悪で世界を平坦にしない。
