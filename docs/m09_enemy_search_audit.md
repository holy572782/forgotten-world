# M09完了後：障害物回避と最後の目撃地点の探索（ADR-059）

2026-11-03、開始時HEAD `4ae8934`。初期の未コミットはmainのDebug Unlimited PursuitをOFFにしたユーザー変更。mainの内容は開始時コピーと一致するまま保持し、今回シーンや入力・描画は変更しない。M09基本戦闘完了／本改善のF5確認待ち、M10別指示待ち。commit／push未実行。

## 原因と修正

- 通常モードは視線喪失1.75秒でRETURNへ移り、迂回途中でも打ち切っていた。修正前の実壁試験では、雑兵・魔導士とも通常モードは命中0でhomeへ帰還し、無制限だけ迂回・命中が成立した。
- 通常追跡への経路接続は実衝突後に限られ、既存Waypointsを保持していても「手前の1セルが空いている」だけで直進へ戻る場合があった。CHASEの直接経路を既存の予算付きpreflightで確認し、証明済みWaypointsを到達／無効化まで維持する。途中1セルの空きだけで全迂回路を捨てない。視界を再取得した通常探索は経路ヒントを破棄し、見える対象へ通常CHASEを再開する。
- 既存ルートの対人停止間隔は現在の主人公位置を参照していた。メモリ追跡ではこの座標を読まず、明示した記憶座標と既知の両カプセル半径＋0.15mで接近地点を作る。最後の地点に主人公や他の身体が残っていても、身体の中心へ侵入しない。実際の歩行／ジャンプ・衝突は従来のEnemyWalkが最終判断する。
- 旧home判定は見えない主人公の現在位置でも帰還を決めていた。通常SEARCHでは目撃座標と敵自身のhome距離だけを使用し、隠れた主人公の移動でメモリや経路目標を更新しない。現在位置への視認Rayは再発見のための感覚判定だけに使う。見えている対象が範囲外なら従来どおり帰還する。

## 行動と時間

既存State enumは追加せず、CHASE／RECOVERYへ`EnemySearch`の論理行動を重ねる。

1. 通常の見える追跡は直接歩行を優先。遮断時だけ既存局所A*を分割実行し、Waypointsを歩く。攻撃可能なら既存のその場攻撃／踏み込み／射撃へ移る。
2. 見失うと最後の目撃地点を固定。既存の1.75秒はLAST_SEENの猶予で、地点へ向かう移動はその後もSEARCH_TRAVELとして継続できる。
3. 同じ高さの足場で身体間隔以内へ着き、記憶地点への視認線も通ることを確認する。到着かつ猶予終了の後、初めてSEARCH_AREAの2秒を数える。先に到着した場合は猶予終了を待つ。到着後のタイマーは移動／目標変更でリセットしない。
4. 記憶地点を中心とした半径2m内の固定方向候補を順に確認する。1描画フレーム1候補、実床・全身端点・home範囲と既存経路を使う。半径0はその場待機。経路がない候補は次へ進み、候補が尽きても新しい探索を無限再生成しない。
5. 再発見でSEARCHを終了してCHASEへ戻る。未発見ならhomeへ戻る。目撃地点への移動を始めて8秒で到達できない場合も打ち切る。この移動期限と到着後の2秒は別タイマー。
6. RECOVERY中に見失った場合も安全な歩行で探索できるが、復帰しても既存の攻撃回復時間／Cooldownは短縮しない。探索が先に終了した場合はRECOVERYの残りを待つ。既存の空中移動は着地まで同じ所有者が継続し、デバッグON/OFFでワープ・空中停止を発生させない。

SEARCH中に攻撃候補や現在の対象位置を計画しない。WINDUP／照準確定後の戦闘は変更せず、ratio0.4／0.5、固定照準、予告・回避猶予、実命中時の壁検査、炎の非追尾／MAGICを維持する。
