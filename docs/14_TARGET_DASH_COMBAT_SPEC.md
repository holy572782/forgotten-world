## 1. 目的・非目的

目的は「攻撃するために敵の足元へ手動接近し続ける必要」をなくし、巨大ボスの全容を見渡す視点と昔のRPGの簡単な敵選択を両立すること。敵を選択し、主人公が視認可能な美しい踏み込みで攻撃し、終了時に元の位置へ帰還する。ボタン入力ごとに明確な一撃を再生する。

**非目的:** 高速連打・複雑なコマンド入力・ジャスト入力・部位破壊・帰還地点の手動選択・新しい踏み込み専用画像の制作は初期実装に含めない。既存のジャンプ画像を仮使用する。

## 2. プレイヤー操作（PC仮割当・既存InputMapを優先）

| 状況 | 入力 | 動作 |
|---|---|---|
| 通常 | WASD/矢印 | カメラ基準で8方向自由移動（M02維持） |
| 通常 | Space | 従来ジャンプ（M03維持） |
| 攻撃可能な敵にカーソル | 右クリック | 敵を選択、攻撃開始位置を記録、美しい踏み込み攻撃へ |
| 戦闘接近中・攻撃中 | 攻撃入力 | 次の一撃を1回だけ予約（残りストックがある場合） |
| 戦闘接近中・攻撃中 | 移動方向キー | 対象を向いたまま指定方向に1回ステップ回避、攻撃を中断または保留 |
| 戦闘接近中・攻撃中 | 防御入力 | 攻撃を中断してガード（キー割当は既存との競合を調べて決定） |
| 戦闘中 | 一定時間追加入力なし | ステップ／防御が終了した後、開始位置へ自動帰還 |
| ストック0 | 攻撃入力 | 追加攻撃不可。操作に応じて防御・回避・帰還は可能 |

クリック選択はゲーム画面上の3D敵とUIの入力競合を排除する。既存のM05攻撃プレビュー用入力はM06実装で整合・移行する。`J`／左クリック等の既存割当を無断破棄せず一覧化してから設定する。

## 3. ターゲットと範囲

- 主人公の水平面上に武器別の円形**攻撃開始可能範囲**を設定する。円の半径は試作値（例: 5m）。カメラから見やすい簡素な円表示。非戦闘中は常時表示せず、敵検出時などに控えめに示す案を初期採用。
- 範囲内で生存・選択可能な敵だけに攻撃マークを表示する。カメラレイから敵の`Targetable`へ接続し、クリック位置に複数候補があれば表示上の最前面を選ぶ。
- 距離だけでなく、高低差・壁・移動経路・着地可否を判定。壁の裏、地形外への飛び込みを禁止。選択不可ならマークを出さない。
- 巨大ボスの部位別ターゲットは後続案であり、初期M06〜M09では敵1体につき1ターゲット。
- ターゲット喪失／死亡／範囲外化では接近を中止して安全な位置へ戻す。

## 4. 攻撃状態機械

`FREE → TARGETED → APPROACH → ATTACK → [ATTACK連続 / GUARD / STEP / RETURN] → FREE`

- `FREE`: 通常移動・ジャンプ。
- `TARGETED`: 選択可否の最終判定、**攻撃開始位置 `return_anchor` を3D座標で保存**。
- `APPROACH`: プレイヤー操作での敵への接近を省略。視認できる速度で敵の正面／指定攻撃位置へ踏み込む。**既存 `player_jump.png` の方向別Jumpコマを仮使用**。通常のSpaceジャンプとは別状態で、二段ジャンプ扱いにしない。
- `ATTACK`: 既存 `player_attack.png` を再生。**一入力＝一斬撃＝一ストック消費**。攻撃判定は見た目の命中フレームに同期し、1対象1斬撃につき原則1ヒット。入力バッファは最大1個（M07）。攻撃後に予約がなければ帰還カウント開始。
- `GUARD`: 攻撃中も呼び出し可能。防御後の追撃・帰還は入力に従う。被弾判定は有効。
- `STEP`: 移動キーの入力方向へ一度だけステップ。敵への向きは維持。キーを押し続けたときの連続ステップを禁止。ステップ後の追撃入力がなければ帰還。
- `RETURN`: **攻撃開始位置**へ視認可能な後退・帰還動作。元位置が壁や敵で塞がれていれば安全な最寄り地点に着地し、その違いをデバッグ表示。帰還中も被ダメージ判定を持つ。帰還中の防御・回避割込みは実装難易度を見てM08で試作・検証する。
- `DEAD/STUNNED`: 既存状態優先順位に従い攻撃・帰還を中断。重複イベントと状態固着を防ぐ。

**自動帰還の仮ルール:** 最終攻撃の入力受付終了後、追加入力なしが0.5秒程度続くと帰還。回避や防御直後にも追撃可能な短い受付時間を設ける。動作中の即帰還を避ける。ゲーム速度・アニメーションに合わせ要調整。

## 5. 攻撃ストック

- M05の`AttackGaugeComponent`（0〜100、時間回復、開始値でダメージ変化）は**旧試作仕様**。完成済みとして消去せず、新設の攻撃ストックへの移行計画と回帰検査を設ける。
- 新ルール: 最大3回（**仮値**）、1攻撃受理で1減る。0では新規攻撃を受理しない。初期満タン。
- ストックは帰還後／`FREE`時に一定間隔で回復（仮値1.5秒に1回）。踏み込み・攻撃・防御・回避・帰還中の回復停止を試作初期値とする。
- `AttackStockComponent`（新設を推奨）で数値、消費、回復、変更通知を所有。HUDはストックの個数をアイコン＋数字で表示し、旧ゲージバーを更新。旧ゲージ依存のダメージ計算は廃止案として別途仕様差分を記録。
- ストック数・回復間隔は`Resource`で調整可能にする。

## 6. ダメージ・防御・回避

- **接近中／攻撃中／帰還中も敵の命中判定は有効**。演出のために全期間無敵にはしない。
- 防御は攻撃を中断し、ガード中の被ダメージ軽減・硬直などは仮値で検証する。
- 回避は敵の方を向いたまま方向キーで横・前・後へステップ。M08の旧「回避無敵」は今回の意図と矛盾しないよう、**ステップの短い回避判定だけ**を設ける案とし、長さや無敵の有無は操作検証で最終判断する。
- **理不尽な被弾を防ぐ:** 帰還中の操作不可時間に発生する被弾、敵の範囲予告、被弾後の帰還処理をテスト対象にする。被弾位置と見た目の攻撃位置がずれないことを優先する。
- 敵は「索敵範囲」「攻撃開始距離」「実際の攻撃判定範囲」を別管理。攻撃範囲に入ると予兆を出して攻撃し、プレイヤー側の接近中も通常どおり判定する。

## 7. アニメーション・カメラ

- **踏み込みの仮アニメーション**: M05で登録済みの`assets/sprites/player/player_jump.png`（48×48px、3列×4方向、透明背景）を使用。方向順は下・左・右・上。上昇相当コマから踏み込み姿勢を選択し、SpriteFramesの共有やアニメーション変更でnull atlasにアクセスしないようM05の修正を維持。
- 攻撃本体は`player_attack.png`、通常移動は`player_walk.png`。新しい専用PNGの制作はしない。
- カメラはM04の**距離維持・遮蔽方式B**を保持。飛び込み時に主人公へ急ズームしない。ボスが画面外へ大きくはみ出す場合はM10で任意のボス戦用フレーミングを比較検証（未決定）。
- 速度よりも「踏み込み→斬撃→余韻→帰還」が見て分かることを評価する。全動作の時間は仮値、動画目視で調整する。

## M07：攻撃ストックと武器別コンボ（2026-10-19）

- 最大3段は初期武器「片手剣」の試作設定で、ゲーム全体の固定上限ではない。WeaponData.max_combo_hitsとAttackStockSettings.maximumは独立。追加攻撃には残段数と必要ストックの両方が必要。武器名による分岐は設けない。
- WeaponDataはscripts/combat/weapon_data.gd、初期Resourceはresources/weapons/one_handed_sword.tres。weapon_id／display_name／max_combo_hits／base_damage／attack_range／combo_input_window／stock_cost_per_hitを使用。攻撃速度倍率とanimation_profileは将来用、M07では未使用。威力10・範囲5mをTargetDashSettingsから移し所有者を一本化した。
- Player/TargetDash.equipped_weaponから取得・設定する。FREE（Idle）のみ参照差し替え可能。戦闘開始時にデータを複製して一巡中の値を固定する。Resourceの共有原本に戦闘進捗を書き戻さない。装備UI・入手・インベントリ・保存・成長・特殊消費は後工程。

## M07追加改善：向き連動照準・固定カメラ・複数敵（2026-10-20）

本節とADR-011を最新仕様とする。前回の左クリック直接指定、カーソル移動中の追撃、J／L選択・攻撃、構えはユーザー手動合格。今回の追加機能は手動未検証でM07は検証待ち。M08へは進まない。
