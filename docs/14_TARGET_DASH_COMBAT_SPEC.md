## 1. 目的・非目的

目的は「攻撃するために敵の足元へ手動接近し続ける必要」をなくし、巨大ボスの全容を見渡す視点と昔のRPGの簡単な敵選択を両立すること。敵を選択し、主人公が視認可能な美しい踏み込みで攻撃し、終了時に元の位置へ帰還する。ボタン入力ごとに明確な一撃を再生する。

## 4. 攻撃状態機械

`FREE → TARGETED → APPROACH → ATTACK → [ATTACK連続 / GUARD / STEP / RETURN] → FREE`

- `FREE`: 通常移動・ジャンプ。
- `TARGETED`: 選択可否の最終判定、**攻撃開始位置 `return_anchor` を3D座標で保存**。
- `APPROACH`: プレイヤー操作での敵への接近を省略。視認できる速度で敵の正面／指定攻撃位置へ踏み込む。**既存 `player_jump.png` の方向別Jumpコマを仮使用**。通常のSpaceジャンプとは別状態で、二段ジャンプ扱いにしない。
- `ATTACK`: 既存 `player_attack.png` を再生。**一入力＝一斬撃＝一ストック消費**。攻撃判定は見た目の命中フレームに同期し、1対象1斬撃につき原則1ヒット。入力バッファは最大1個（M07）。攻撃後に予約がなければ帰還カウント開始。
- `GUARD`: 攻撃中も呼び出し可能。防御後の追撃・帰還は入力に従う。被弾判定は有効。
- `STEP`: 移動キーの入力方向へ一度だけステップ。敵への向きは維持。キーを押し続けたときの連続ステップを禁止。ステップ後の追撃入力がなければ帰還。
- `RETURN`: **攻撃開始位置**へ視認可能な後退・帰還動作。元位置が壁や敵で塞がれていれば安全な最寄り地点に着地し、その違いをデバッグ表示。帰還中も被ダメージ判定を持つ。帰還中の防御・回避割込みは実装難易度を見てM08で試作・検証する。
- `DEAD/STUNNED`: 既存状態優先順位に従い攻撃・帰還を中断。重複イベントと状態固着を防ぐ。

**自動帰還の仮ルール:** 最終攻撃の入力受付終了後、追加入力なしが0.5秒程度続くと帰還。回避や防御直後にも追撃可能な短い受付時間を設ける。動作中の即帰還を避ける。ゲーム速度・アニメーションに合わせ要調整。

## 5. 攻撃ストック

- M05の`AttackGaugeComponent`（0〜100、時間回復、開始値でダメージ変化）は**旧試作仕様**。完成済みとして消去せず、新設の攻撃ストックへの移行計画と回帰検査を設ける。
- 新ルール: 最大3回（**仮値**）、1攻撃受理で1減る。0では新規攻撃を受理しない。初期満タン。
- ストックは帰還後／`FREE`時に一定間隔で回復（仮値1.5秒に1回）。踏み込み・攻撃・防御・回避・帰還中の回復停止を試作初期値とする。
- `AttackStockComponent`（新設を推奨）で数値、消費、回復、変更通知を所有。HUDはストックの個数をアイコン＋数字で表示し、旧ゲージバーを更新。旧ゲージ依存のダメージ計算は廃止案として別途仕様差分を記録。
- ストック数・回復間隔は`Resource`で調整可能にする。

## 6. ダメージ・防御・回避

- **接近中／攻撃中／帰還中も敵の命中判定は有効**。演出のために全期間無敵にはしない。
- 防御は攻撃を中断し、ガード中の被ダメージ軽減・硬直などは仮値で検証する。
- 回避は敵の方を向いたまま方向キーで横・前・後へステップ。M08の旧「回避無敵」は今回の意図と矛盾しないよう、**ステップの短い回避判定だけ**を設ける案とし、長さや無敵の有無は操作検証で最終判断する。
- **理不尽な被弾を防ぐ:** 帰還中の操作不可時間に発生する被弾、敵の範囲予告、被弾後の帰還処理をテスト対象にする。被弾位置と見た目の攻撃位置がずれないことを優先する。
- 敵は「索敵範囲」「攻撃開始距離」「実際の攻撃判定範囲」を別管理。攻撃範囲に入ると予兆を出して攻撃し、プレイヤー側の接近中も通常どおり判定する。

### ADR-054：表示用計画の分割と負荷診断
