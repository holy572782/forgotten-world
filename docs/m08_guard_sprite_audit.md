## 48px基準・インポート・表示

既存M05と同じ基準 `(24,47)`、最下部の可視画素y=46、下余白1px。セル全体を使い、主ノード位置0、`offset=(0,23)`（47−48/2）、`pixel_size=0.0375`、Nearest、ミップなし、透明背景を維持。ポーズ別の可視範囲の中心へ寄せ直さない。48pxの表示幅は1.8mで、カプセルと足元原点は変更しない。

インポートは既存と同じlossless、`fix_alpha_border=false`、`premult_alpha=false`、`size_limit=0`、`detect_3d/compress_to=0`。AtlasTextureは明示した12矩形と`filter_clip=true`。Godotインポート後の全RGBA画素と各Atlasの画素を元画像に照合する。

## 検証と操作

実行結果と環境制約は`DEVELOPMENT_STATUS.md`の2026-10-21作業ログ、再実行コマンドは`12_TEST_PLAN.md`を参照。ヘッドレス検査と実描画・目視、ユーザー操作の受入を区別する。

1. Godotで`project.godot`を開き、インポート終了後F5。WASDで各向きへ歩いて停止し、Iを押し続ける。敵が選択されていれば防御は既存仕様どおり敵方向を向く。敵がいない平地で各向きを確認するか、I保持中にQ/Eでカメラを回す。
2. 4方向で盾を構えた主人公全体が出る。中央コマを静止表示し、白背景・別の人物の端・二重表示がなく、足元がずれないこと。Iを放すと盾画像が消える。
3. 解除後WASD・Spaceで歩行／ジャンプ／落下／着地へ戻る。Q/E回転でも方向が対応する。壁の背後で既存の半透明化と足元の遮蔽を確認する。
4. 敵をクリックまたはJで踏み込み、接近・攻撃中にIで割り込み。盾を表示して停止する。I解除後にJで追撃、または無入力で元地点へ帰還。帰還中Iでも盾へ移り、解除で帰還再開する。
5. 戦闘開始前から移動を保持した場合は全解放してからWASD／矢印を新規入力する。既存の方向帰還が1回だけ開始し、盾が残らず、カメラ固定・ストック・連撃が従来どおりであること。帰還後は方向キーを放して通常移動・Spaceを確認する。

上記の実キーボードでの操作感、実機パッドLB、長時間性能、複雑地形・大型敵はユーザー手動検証待ち。現行の敵は自動攻撃しないため、軽減率はHealthComponent経由の既存自動検査で確認し、敵からの実操作被弾を確認済みとはしない。
