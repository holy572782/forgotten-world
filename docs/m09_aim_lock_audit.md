# M09完了後：雑兵・魔導士の位置確定型攻撃（ADR-055）

2026-11-02。開始時の作業ツリーはclean、基準revisionは`220a51d`。ユーザーの今回の指示に「ADR-053・054後のFPS低下はF5確認で解消」とあり、性能修正のユーザー確認を受領した。M09基本戦闘完了は維持、本件のAI操作感は別途F5確認待ち、M10別指示待ち。commit／pushは未実行。

## 変更前と目的

従来の雑兵は予告中の主人公を追い、予告終了時に狙いを固定していた。魔導士は予告開始後に射程外へ逃げられても発射するが、発射時点の現在位置で再照準していた。今回、敵の攻撃データで共通の`aim_lock_ratio`を管理し、指定時刻に一度だけ狙いを確定する。主人公の自動選択・マーク・コンボや通常歩行／ジャンプ、共有の地形判定は改修しない。

## Inspectorの設定

FileSystemで`resources/enemies/melee_attack.tres`または`ranged_attack.tres`を開き、**Aim Lock Ratio**を変更する。0～1、刻み0.01。0は予告開始、1は予告終了。攻撃Resourceを別名保存／Make Uniqueにすれば、敵個体・攻撃技ごとの値を持てる。Enemy Settingsの**Attack**へそのResourceを割り当てる。通常は停止中に編集・保存してF5で適用する。Remoteで実行中の設定Resourceを変更した場合は、開始済みの攻撃を変えず、次の攻撃のsnapshotへ反映する。

| 対象 | 初期ratio | 予告時間 | 初期の確定時刻 |
| --- | ---: | ---: | ---: |
| 雑兵 | 0.4 | 0.9秒（維持） | 約0.36秒 |
| 魔導士 | 0.5 | 1.0秒（維持） | 約0.50秒 |

既存／未指定の攻撃Resourceの既定は0.0で、旧来の予告開始時固定と互換。snapshotで非有限値を0へ戻し、範囲外の値は0～1へ制限する。

最低猶予は重複設定を作らず、既存Enemy Settingsの**Aim Commitment → Aim Commit Minimum Seconds**（初期0.45秒、0.1～1.5秒）を使う。雑兵は確定から命中まで（移動・到着待ち・命中delayを含む）、魔導士は確定から発射まで。雑兵は以前の「予告終了→命中にも最低0.45秒」という待機を残し、照準だけ早く固定しても攻撃自体が早まらない。初期設定の雑兵は従来と同じく約1.35秒後の命中、魔導士は1秒後の発射。魔導士のratio=1など残り猶予が不足する設定だけ発射を遅らせる。魔法は発射後の飛行時間も実際の回避猶予に加わる。

以前の`track_windup_target`／`windup_replan_grace_seconds`は既存Resourceの読み込み互換のため残すが、今回の敵の照準時刻や再照準を制御しない。新しい照準設定はAttackのratioに一本化する。ADR-037・045・052・053にある「予告終了時固定」「発射時の現在位置」「移動先を追う予告中再計画」は本ADRで置き換える。既存の他の性能／安全条件は維持する。

## 雑兵の処理

1. CHASEの候補判定はADR-054の短期保存／分割を使用する。予告開始時は最新の生存・認識条件を軽く確認し、着地点の全探索を繰り返さない。
2. WINDUP中、確定前は表示用の向き・目標位置だけ主人公に追従する。赤点滅とFire1の開始時1回再生は既存のまま。
3. 閾値に達すると`_lock_aim()`が実ワールド座標と方向を一度記録し、`aim_locked`／`aim_lock_elapsed`を設定、`aim_committed`を1回通知する。足元地面への投影も、この保存座標から取得して固定する。攻撃開始地点も実座標から`attack_anchor`へ記録する（WINDUP中は停止するため通常は予告開始地点と同じ）。
4. 安全計画は`Elevation.new_attack_job()`／`attack_step()`を再利用し、1描画フレーム1候補・共通PlanningBudget内で進める。待機中に目標を取得し直さない。候補ごとの剣・着地・全身往復の安全証明は同時点で完結させる。
5. その場で届けばその場攻撃。移動が必要なら確定済みの着地点へ向かう。計画未完了では動かず、全候補不成立は安全に中断してRECOVERYへ。予算待ちが予告終了から2秒を超えても発進せず中断する。
6. 発進直前は同じ着地点への往復を新たに検証する。着地点を再探索したり、逃げる主人公へ方向を修正したりしない。実移動は既存の衝突・支持／跳躍処理、実命中は固定向きの剣と現在の主人公の位置／地形で判定する。
7. 帰還後は既存RECOVERYと戦闘中移動へ戻る。次の予告でフラグとジョブを初期化し、新たな狙いを取得する。

## 魔導士の処理

共通イベントで固定した主人公の座標へ従来と同じUP 0.9mを加え、発射時の実際のmuzzle（魔導士位置＋UP 0.9m）との差から炎の玉の方向を決める。発射後の弾処理は変更せず直進・実衝突で判定する。

位置確定後、現在の主人公だけが射程外／遮蔽物の後ろへ移動しても照準・発射を変更しない。固定地点への地形の射線とmuzzleの実球形状の重なりを確認し、発射地点が壁内なら弾自体を生成しない。固定射線に新しい壁ができた場合も生成しない。現在の主人公の視線を発射条件には使わない。

確定後の攻撃中は、現在の対象までの距離／視線喪失だけで攻撃を追尾・打ち切らない。正式home範囲を越えた対象への攻撃が終わった後は従来どおりhomeへ戻る。主人公／敵の死亡・消失は安全終了を優先する。弾速5m/s・距離13.2m・半径0.2m・見た目1.8m、MAGIC防御貫通、魔法陣・Magic1／Fire3／命中演出、回復10秒は維持する。

### 既存テストの更新で確認したこと

- 攻撃入口の即時計画や「予告終了時固定」は新仕様と異なるため、照準確定と分割計画完了を待ってから同じ安全条件を検査する。ジャンプ頂点は既存の剣の実命中時刻へ合わせ直し、命中高さ・1回のダメージ・帰還の条件は変えない。
- 旧enemy_terrainの幅3mの台は、基準220a51dでも今回でも、足元(0,0,0)から(2.599066,0.001563,0)へ安全な平地踏み込みが成立し、その場攻撃ではなかった。これを「踏み込めないので歩く」失敗と扱う前提が古かった。テストは実際の連続坂へ置き換え、戦闘跳躍OFFでも通常歩行で約1.03m接近してその場攻撃へ入ることを確認する。歩行実装は変更しない。
- 旧mage_magicの崖停止は前後とも(0,0.000835,13.60001)、実支持あり・NO_WALKABLE_SUPPORTで安全停止した。厳密なY=0という期待だけを、3mm未満の接触補正＋元のZ上限＋実足場支持へ更新。ゲーム側の許容値は広げていない。
- 30FPSでは描画の間にphysicsが2tick進み、帰還直後の既存歩行が始まる。その場の遅い描画位置ではなく、既存ReturnTraceのRECOVERYへ入った瞬間の実位置で帰還を検査する。新規の壁を置く試験ではphysicsへの登録を待って問い合わせる。

F5での最終的な回避のしやすさ・敵の読みやすさ、長時間／多数敵の性能、ユーザー個別の複雑地形は未確認。M09基本戦闘の完了と、今回のAIのユーザーF5確認待ちを区別する。
